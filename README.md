Código, exercícios e diário de progresso da minha prática diária de programação em Java.

## Sobre este repositório

Este repositório documenta minha prática de código, escrita e revisão como parte da minha preparação técnica para vagas de desenvolvedor júnior.

O núcleo do processo é uma regra simples: **90 minutos por dia útil, código escrito a partir de um arquivo vazio, com IA completamente fechada** - sem Copilot, sem ChatGPT, sem Stack Overflow. Apenas documentação oficial (Oracle Java Docs, Spring Docs, Livros e Apostilas) é permitida. Todo exercício registrado aqui foi resolvido assim.

## Como ler o `diario.md`

Cada dia de estudo segue o padrão:

```
📆 AAAA-MM-DD | ⌛ Xmin
- 📝 [Nome do exercício] ([linguagem]) | 📍 Local: [link ou arquivo] | 👀 Travei: [Sim (motivo) / Não] | [✅/❌] Resolvi sozinho: [Sim/Não]

```

## Como ler os commits

Cada commit de um dia de estudo segue o padrão:

```
Dia N (DD/MM) | Exercícios: X (resolvidos: Y, travei: Z)
```

`Exercícios` conta tudo que foi tentado no dia. `resolvidos` conta só o que saiu sem travar. `travei` é o que ficou pendente ou foi retomado depois.

## Sobre o uso de IA

Uso IA de forma deliberada, mas não na escrita dos exercícios registrados aqui. Primeiro escrevo minha própria versão, sozinho; só depois abro ferramentas de IA para revisão e crítica. Essa separação garante que a fluência de base seja genuinamente minha.
